# LasseReviews 2.0 – iPad-Anleitung

Diese Website ist zweisprachig (DE/EN) und benötigt keine kostenpflichtigen Dienste.

## Aktualisieren
1. Öffne https://github.com/lasseabi/lassereviews in Safari.
2. Wähle **Add file → Upload files** (ggf. unter dem kleinen Pfeil neben Add file).
3. Lade die **entpackten** sechs Dateien `index.html`, `style.css`, `app.js`, `reviews.js`, `i18n.js`, `README.md` in das Hauptverzeichnis hoch.
4. Bestätige, dass vorhandene Dateien überschrieben werden, und tippe auf **Commit changes**.
5. Warte 1–5 Minuten und öffne https://lasseabi.github.io/lassereviews/ . Aktualisiere Safari ggf.

## Eigene Rezensionen
In `reviews.js` liegen die Texte. `body` ist Deutsch, `body_en` Englisch; `excerpt` und `excerpt_en` sind die Kurztexte. Das Original zu Konklave wurde aus dem bereitgestellten Screenshot übertragen.

## Vor dem professionellen Einsatz
Ersetze in `index.html` die Platzhalter-E-Mail `DEINE-EMAIL@BEISPIEL.DE` und den IMDb-Link. Prüfe Impressum/Datenschutz nach geltendem Recht. Verwende nur Filmplakate mit passenden Nutzungsrechten.
